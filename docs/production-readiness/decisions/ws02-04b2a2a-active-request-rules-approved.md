## Decision

The Project owner approves preserving the current implemented request-policy
values, literal sets, and dynamic safeguards listed below for
WS02-04B2A2A-owned active workflow request validation.

This approval is limited to current reachable behavior that already exists in
the accepted source tree and remains compatible with current supported callers.
It does not approve unrelated current schema constraints merely because they
exist.

## Evidence Boundary

This decision approves source-owned request rules only. It does not claim
provider dashboards, deployed runtime behavior, multi-instance concurrency,
database invariant closure, telemetry dashboards, alert thresholds, or external
evidence.

## Change Rule

Any future change to an approved A2A rule requires either an already-authorized
later owner or a superseding owner decision. The limits register may record this
decision but is not itself approving authority.
