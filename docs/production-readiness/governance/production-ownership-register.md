# Production Ownership Register

Primary control: GOV-004.

Approved model: the project owner serves as the interim accountable owner for each separate production role hat until responsibilities are reassigned. Role hats remain separate even when held by the same person. Backup and escalation coverage is unassigned unless an explicit future record says otherwise.

## Review Rule

This register changes only through an approved ownership update or superseding decision record. Reassignment must include evidence transfer and provider-access/offboarding review; naming one interim owner for all hats is an explicit development state, not complete production resilience.
