# Provider Control-Plane Register

Pass: EN-03.

Primary controls: OPS-005, OPS-025.

Owner role: Secrets and provider access owner, held by Project owner (interim) until reassigned under the approved ownership model.

Evidence basis: repository source, environment examples, README deployment notes, GitHub Actions workflow configuration, GOV-01 governance records, EN-01 and EN-02 planning records, and the finalized audit/remediation records. No provider dashboards, accounts, secrets, billing pages, production deployments, DNS records, or runtime settings were accessed.

## Status Vocabulary

- `NOT YET EVIDENCED`: the repository identifies the provider or need, but no sanitized provider evidence has been reviewed.
- `UNKNOWN`: the fact is not knowable from repository evidence.
- `NOT SELECTED`: no provider has been chosen in repository evidence.
- `NOT APPLICABLE`: the field does not apply to the provider or current repository usage.
- `PARTIAL`: repository evidence exists, but provider or runtime evidence is still required.
