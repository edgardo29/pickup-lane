# Limits And Thresholds Register

Primary control: GOV-006.

Owner role: Observability and reliability owner with domain participation from platform, API, database, payments, storage, durable jobs, frontend, quality, privacy, and finance roles as applicable. All roles are held by Project owner (interim) until reassigned.

Method: every limit or threshold value must be selected from evidence. This register intentionally records open values as `TBD - owner decision and evidence required`.

## Approval Rule

A row can move out of `TBD - owner decision and evidence required` only with an approved decision record, linked boundary tests, telemetry plan, and source/provider/runtime evidence appropriate to the enforcing layers. This register does not approve numeric values.
