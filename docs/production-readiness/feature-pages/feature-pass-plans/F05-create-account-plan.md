# F05 — Create Account Feature Pass Plan

**Page specification:** `docs/production-readiness/feature-pages/pages/player-facing/F05-create-account-spec.md`  
**Endpoints:** The email step reads `GET /auth/email-availability`. Google sign-in uses Firebase, followed by `GET /auth/me`. The connected Finish Profile flow uses `POST /auth/sync-user` and `PATCH /users/me`; unfinished Google signup uses `DELETE /auth/unfinished-account`. Saved record destinations use `GET /games/{game_id}` or `GET /need-a-sub/posts/{sub_post_id}`. Email/password identity creation happens in Firebase only after valid Finish Profile submission.
