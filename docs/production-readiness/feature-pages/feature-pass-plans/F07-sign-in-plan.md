# F07 — Sign In Feature Pass Plan

**Page specification:** `docs/production-readiness/feature-pages/pages/player-facing/F07-sign-in-spec.md`  
**Endpoints:** Firebase authenticates email/password and Google sign-ins directly from the browser. Pickup Lane loads the account with `GET /auth/me`; the connected Finish Profile flow uses `POST /auth/sync-user` when no application account exists and `PATCH /users/me` to save profile details. Resource returns use the existing `GET /games/{game_id}` and `GET /need-a-sub/posts/{sub_post_id}` visibility checks. The connected Edit Game check also loads `GET /venues/{venue_id}` and `GET /community-game-details/games/{game_id}/host-edit`. `GET /account-suspended` exposes only the signed-in account's suspension notice, independently of Inbox. Existing-commitment checks use `GET /my-games` and `GET /my-games/need-a-sub`. The suspension checks exercise only the access gates on community publication, Sub Post creation, game joining, checkout guest addition, and Sub Post requests.
